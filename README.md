# BIOVAULT — Defiende el Refugio (demo promocional)

Mini-juego de supervivencia por oleadas, estilo arcade/CRT, hecho en un solo archivo
HTML con Canvas 2D y Web Audio API (sin assets externos).

**Jugar:** https://beefungislp-sys.github.io/biovault-promo/

## Cómo se juega
- Defiende el **Reactor** y los **módulos de comida** de oleadas de raiders.
- **Clic** sobre los raiders para repelerlos (¡cuidado, tus clics también dañan a tus habitantes!).
- Entre oleadas eliges: **sumar habitantes** o **reparar módulos**.
- Sobrevive las **7 oleadas** (con 2 jefes en la última).
- Tecla **M** para silenciar el audio.
